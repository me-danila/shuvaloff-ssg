# Заявки на розыгрыш «Графские выходные»

Форма отправляет письмо через Web3Forms. После его подтверждения сайт сохраняет копию с тем же ID вне каталога публикации. Скрипт привязан к [таблице заявок](https://docs.google.com/spreadsheets/d/1C6YkSo6kYiXZLS3MGANannA_IAfuxwnhfAQBoqerccY/edit). Каждые пять минут он забирает до 50 записей из очереди каждого лендинга и записывает их на соответствующий лист по его ID. Сайт удаляет их после подтверждения записи в Google Sheets. При сбое подтверждения скрипт узнаёт уже записанные строки по ID в колонке A.

## Настройка сервера

На `al.spb` основной виртуальный хост остаётся статическим (`enableScript 0`). После правила перенаправления на HTTPS в `vhosts/academia-shuvaloff.ru/vhconf.conf` настроен точный маршрут:

```apache
RewriteRule ^/?api/poseidon\.php$ http://poseidon-queue/poseidon.php [P,L]
```

Прокси OpenLiteSpeed `poseidon-queue` направляет запрос на `127.0.0.1:18265`. Этот локальный listener обслуживает только виртуальный хост `poseidon-queue` с корнем `/usr/local/lsws/academia-shuvaloff.ru/current/api/`. Его LSAPI-обработчик `poseidon-php` запускает PHP 8.3 с `mbstring` от отдельного системного пользователя и группы `poseidon-queue`.

Очередь находится вне релизов. Каталоги создаются от root:

```sh
install -d -m 0750 -o root -g poseidon-queue /var/lib/academia-shuvaloff/poseidon
install -d -m 0700 -o poseidon-queue -g poseidon-queue /var/lib/academia-shuvaloff/poseidon/pending
```

Опубликуйте сайт штатной командой `bun run deploy`.

Очередь «Посейдона» остаётся в `pending/`. Для новых акций обработчик создаёт подкаталоги `simamma`, `pinci`, `siberianlights` и `msk-ist` при первом обращении. Для каждой акции операции чтения и подтверждения работают только в её каталоге.

## Обновление действующей таблицы

Сначала опубликуйте обновлённый PHP-обработчик. В существующем привязанном проекте Apps Script замените содержимое файла на [Code.gs](Code.gs) и сохраните. Действующий триггер продолжит вызывать `syncPoseidon` с прежним ключом. Названия книги и листов можно менять: соответствие задаётся в `campaignSheets` по постоянным ID. После обновления проверьте успешное выполнение в истории Apps Script.

## Первоначальная настройка Google

1. Из общей таблицы по ссылке выше откройте **Расширения → Apps Script**.
2. Поместите содержимое [Code.gs](Code.gs) в редактор и сохраните.
3. Запустите `installPoseidonSync` и разрешите доступ. Скрипт создаст ключ в Script Properties, добавит его публичный SHA-256 в примечание A1 и установит триггер.
4. Администратор сайта сверяет примечание A1 в указанной таблице и записывает только 64 шестнадцатеричных символа отпечатка в `/var/lib/academia-shuvaloff/poseidon/sync.sha256` (владелец root, группа poseidon-queue, режим 0640). До этого выдача заявок заблокирована.
5. В Apps Script откройте **Триггеры** и проверьте расписание `syncPoseidon`. История и ошибки доступны в **Выполнениях**.

Устанавливает один владелец. При переносе владельца удалите старый триггер и выполните установку из нового аккаунта. Сохраняйте порядок и названия первых шести колонок каждого листа. Для A2:F установлен формат «Обычный текст», чтобы Google сохранял ведущий плюс телефона и ввод участника буквально. Храните доступ к скрипту и таблице у сотрудников, которые обрабатывают заявки.
