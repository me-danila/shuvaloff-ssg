# Что нужно для запуска розыгрыша «Москва-Стамбул»

Адрес для QR-кода и рекламы после публикации — `https://academia-shuvaloff.ru/msk-ist?utm_source=msk-ist`.

| Что требуется | Что осталось сделать |
| --- | --- |
| Полные правила акции | Загрузить утверждённый PDF в S3 под ключом `files/msk-ist_rules.pdf`. |
| Почта для заявок | Выбран общий ключ Web3Forms «Посейдона». В теме письма указано название ресторана. |
| Google Таблица | Готов [лист «Москва-Стамбул»](https://docs.google.com/spreadsheets/d/1C6YkSo6kYiXZLS3MGANannA_IAfuxwnhfAQBoqerccY/edit#gid=778083110) в общей таблице. |
| Синхронизация | Опубликовать обновлённый обработчик сайта и сохранить [общий скрипт](../poseidon/Code.gs) в существующем проекте Apps Script. |

После подключения проверить одну согласованную тестовую заявку. Её ID должен совпасть в письме менеджеру и строке таблицы. После успешной отправки форма должна открыть `/msk-ist/thankyou/`. В модуле бронирования проверить, что код `Мск Стамбул` применяет скидку 15%.

Лендинг проверяет доступность файла при открытии страницы. После публикации PDF при следующей загрузке страницы станут доступны форма и [правила акции](https://static.academia.spb.ru/files/msk-ist_rules.pdf).
