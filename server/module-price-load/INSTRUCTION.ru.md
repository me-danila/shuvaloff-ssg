# Модуль автовыгрузки цены

## Установка <a name="install"></a>

1) Скопируйте папку `module-price-load` в корень сайта.  

2) Установите настройки модуля в соответствии с [документацией (пункт "Настройки выгрузки цен")](core/README.ru.md#settings).
  
3) Обратитесь к хостингу, либо установите задачу на Cron самостоятельно: нужно запускать скрипт `module-price-load/core/execute.php` раз в 4 часа. Пример запуска скрипта на Cron:
  
   ```
   0 */4 * * * /usr/local/bin/php7.1 ~/YOUR-DOMAIN.RU/public_html/module-price-load/core/execute.php
   ```
   
4) Запустите скрипт вручную один раз, дождитесь загрузки цен (~5s-2m). Вместо консольной команды можно запустить Cron задачу через панель управления на хостинге.

   ```
    /usr/local/bin/php7.1 ~/YOUR-DOMAIN.RU/public_html/module-price-load/core/execute.php - пример команды на хостинге Beget
   ```

5) Проверьте [файл с ценами](core/README.ru.md#prices) и [логи](core/README.ru.md#log). Файл должен содержать информацию о ценах отелей и номеров. В файле логов должно быть сообщение об успешном завершении работы.

6) Можно проверить выгруженные цены по адресу `<домен>/module-price-load/demo/`. Доступ к странице ограничен.

7) Подключите скрипт `module-price-load/assets/public/price-autoload.js` в футере сайта.
  
8) В коде сайта у необходимых элементов установите дата-атрибуты в соответствии с [документацией (пункт "Вывод информации о ценах на сайт")](assets/README.ru.md#attributes).

## Доработка файлов модуля <a name="changes"></a>

1) Исходные файлы js скрипта `module-price-load/assets/public/price-autoload.js` (выводит цены на сайт) править можно.

2) Исходные файлы php скрипта `module-price-load/core` (выгружает цены с помощью API) править крайне не рекомендуется.  
Если возникнет такая необходимость, сначала напишите человеку, ответственному за этот модуль с предложением о доработках.  
Если вы договорились делать правки локально на своем сайте, в таком случае правки вносить можно.  
Самое главное: сократить локальные доработки на сайтах, чтобы совершенствовать исходный модуль.

(!) При внесении правок в php скрипт `module-price-load/core` опишите внесенные изменения в файле `module-price-load/changes.txt`, чтобы другим разработчикам было проще разобраться в проблеме при дальнейших доработках.

## Тестовый запуск (Open Server) <a name="test-start"></a>

1) Разверните папку `module-price-load` на Open Server. Установите настройки в соответствии с [требованиями](REQUIREMENTS.ru.md).

2) Установите настройки модуля в соответствии с [документацией (пункт "Настройки выгрузки цен")](core/README.ru.md#settings).
  
3) Откройте консоль Open Server, выполните запуск скрипта `module-price-load/core/execute.php` командой:

   ```
   php <полный путь до файла>/module-price-load/core/execute.php
   ```

4) Дождитесь выгрузки цен (~5s-2m).  

5) Проверьте [файл с ценами](core/README.ru.md#prices) и [логи](core/README.ru.md#log). Файл должен содержать информацию о ценах отелей и номеров. В файле логов должно быть сообщение об успешном завершении работы.

6) Откройте демо в браузере по адресу `<домен>/module-price-load/demo/`.
