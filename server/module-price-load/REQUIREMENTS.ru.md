# Модуль автовыгрузки цены
## Технические требования

__Требования к хостингу для установки модуля автовыгрузки:__

На хостинге должна быть возможность настроить крон задачу с указанием версии php не ниже 7.1.

Пример: `/usr/local/bin/php7.1 ~/YOUR-DOMAIN.RU/public_html/module-price-load/core/execute.php` (здесь указана конкретная версия).

При этом не важно на какой версии php работает сам сайт, т.к. модуль автовыгрузки - это независимый скрипт.

Параметр php `allow_url_fopen` для версии php не ниже 7.1 на хостинге должен быть равен значению `On`.

На сервере должен быть установлен модуль `curl` версии не ниже 7.30.

Если требования не выполняются, то модуль установить нельзя.

======================

Разработчикам:
Если на сайте установлена старая версия модуля, и её необходимо обновить, а хостинг не отвечает заданным требованиям, то придётся вносить правки в модуль автовыгрузки по ситуации.
