### Вывод информации о ценах на сайт <a name="attributes"></a>

Скрипт `module-price-load/assets/public/price-autoload.js` выводит цены на сайт на основе нижеперечисленных атрибутов. 

Для каждого параметра, который надо вывести (цена, название тарифа, количество людей, дата, ссылка), **нужен отдельный тег html**. Значения цены/даты/minlos/тарифа добавляются внутрь тега с дата-атрибутами, поэтому всё содержимое тегов, у которых заданы эти атрибуты, **удалится**.

* `data-module-price-load-hotel-id` _(обязательный)_ - id отеля.
* `data-module-price-load-room-type` _(обязательный для вывода цены за номер)_ - id комнаты.
* `data-module-price-load-currency` _(обязательный для вывода цены)_ - валюта цены. Атрибут необходим только для вывода цены. Для всех остальных данных, указанных ниже, атрибут указывать не нужно.
* `data-module-price-load-adults` - количество людей минимальной цены. Если не указать этот атрибут, выведется минимальная цена среди всех размещений.
* `data-module-price-load-date` - атрибут для вывода даты. Если указать этот атрибут, вместо цены выведется дата минимальной цены указанных выше параметров.
* `data-module-price-load-minlos` - атрибут для вывода периода бронирования. Если указать этот атрибут, вместо цены выведется период бронирования в днях, в течение которого доступно бронирование по выгруженной цене.
* `data-module-price-load-offer-name` - атрибут для вывода названия тарифа. Если указать этот атрибут, вместо цены выведется название тарифа, из которого была получена цена.
* `data-module-price-load-link` - атрибут для вывода ссылки на бронирование номера. Если указать этот атрибут, на место атрибута ссылки (href) выведется ссылка для бронирования номера. По умолчанию подставляется только room-type. Можно указать в атрибуте через запятую, какие данные должны передеваться в ссылке. Доступные данные:
    * `hotel` - id отеля
    * `room` - id комнаты
    * `date` - дата выгруженной цены
    * `nights` - количество ночей для бронирования
    * `adults` - количество взрослых
    * `offer` - id тарифа выгруженной цены
* `data-module-price-load-link-book-url` - дополнительный атрибут для `data-module-price-load-link`. В нём нужно указать ссылку, по которой должно происходить бронирование номера. Например, `/en/booking/`, `//subdomain.domain.com/reservation/`. К этой ссылке будут добавлены гет-параметры, которые указаны выше.
* `data-module-price-load-extra-placement-price` - атрибут для вывода цены за дополнительное место. Если указать этот атрибут, вместо основной цены выведется цена за дополнительное место (extra_adult). Цена доступна только если в API есть данные о дополнительном размещении для номера.

#### Примеры

Минимальная цена на весь отель:

```
<span data-module-price-load-hotel-id="11"
      data-module-price-load-currency="RUB">
</span>
```

Минимальная цена за номер:

```
<span data-module-price-load-hotel-id="11"
      data-module-price-load-room-type="12345"
      data-module-price-load-currency="RUB">
</span>
```

Минимальная цена за номер для 2-х гостей:

```
<span data-module-price-load-hotel-id="11"
      data-module-price-load-room-type="12345"
      data-module-price-load-adults="2"
      data-module-price-load-currency="RUB">
</span>
```

Дата минимальной цены:

```
<span data-module-price-load-hotel-id="11"
      data-module-price-load-room-type="12345"
      data-module-price-load-date>
</span>
```

Ссылка и дата минимальной цены за номер:

```
<a data-module-price-load-hotel-id="11"
   data-module-price-load-room-type="12345"
   data-module-price-load-link="room,date,nights"
   data-module-price-load-link-book-url="/en/booking/">
    <span data-module-price-load-hotel-id="11"
          data-module-price-load-room-type="12345"
          data-module-price-load-date>
    </span>
</a>
```

Цена за дополнительное место:

```
<span data-module-price-load-hotel-id="11"
      data-module-price-load-room-type="12345"
      data-module-price-load-currency="RUB"
      data-module-price-load-extra-placement-price>
</span>
```

### Настройки текстов для вывода на сайт <a name="front-settings"></a>

Настройки указываются в файле `module-price-load/assets/src/js/settings.js`.  
По умолчанию тексты уже заданы для `ru` и `en` языков.

**Все настройки обязательные.**

Настройки необходимо указать **для каждой языковой версии** сайта.

Язык сайта определяется на основе атрибута `lang` тега `html`.

* `DateText`: _string_ - текст для вывода информации о дате цены.
    * `PLACEHOLDER.DateFormat` - место, куда добавится дата в указанном тексте.
* `DateFormat`: _string_ - формат вывода даты. Можно настроить, чтобы выводилось название текста в нужном падеже, но нужны переводы (для ру языка настройки есть). Настройки формата даты можно посмотреть в документации https://day.js.org/docs/en/display/format
    * Текстовое название месяца выставляется в соответствии с указанным языком только если месяц задан в формате `MMMM`.
* `MinLosText`: _string_ - текст для вывода информации о minLos.
    * `PLACEHOLDER.MinLos` - место, куда добавится количество дней для бронирования.
    * `PLACEHOLDER.MinLosDay` - место, куда добавится текст "дня/дней" в зависимости от языка.
    * `PLACEHOLDER.MinLosEnd` - место, куда добавится окончание числительного (-го/-х/-и) (только для русского языка).
* `OfferText`: _string_ - текст для вывода информации о тарифе.
    * `PLACEHOLDER.Offer` - место, куда добавится название тарифа на нужном языке.
* `UsePriceRound`: _ROUND_OPTION type_ - способ округления цен.
    * `ROUND_OPTION.No` - не использовать округление.
    * `ROUND_OPTION.RoundDown` - округление в меньшую сторону.
    * `ROUND_OPTION.RoundUp` - округление в большую сторону.
    * `ROUND_OPTION.RoundNearest` - округление до ближайшего целого.
* `UsePriceSplit`: _boolean_ - использовать разделение цифр в цене пробелами меджу тысячными разрядами (например, 3 000, 1 500 000).
* `PriceDelimiter`: _string_ - указать символ-разделитель целой и дробной части цены.

### Метод вывода информации о ценах на сайт <a name="method"></a>

`setLoadedPrices(selector?: string): void` - метод, который выводит на сайте цены и связанную с ценами информацию на основании атрибутов, перечисленных выше в документации.

__Параметры:__

* `selector: string` _(необязательный)_ - селектор DOM элемента, в котором или внутри которого нужно установить цены или связанную с ценами информацию. Формат строки - `DOMString`, т.е. формат параметра метода `querySelectorAll`. Если значение не указывать, метод будет искать подходящие контейнеры на всей странице.

Метод автоматически срабатывает после загрузки DOM дерева, поэтому отдельно его вызывать нужно только при необходимости. Например, для обработки элементов на странице, которые появляются уже после загрузки DOM.

### Скрипт отображения цен <a name="price-autoload"></a>

Необходимо подключить скрипт вывода цен `module-price-load/assets/public/price-autoload.js` в футере сайта, чтобы он начал выводить на сайте выгруженные цены. 

Этот скрипт можно изменяться локально (на сайте), если есть необходимость.

При необходимости можно добавить стили. 

Пересобрать скрипт и стили можно командой ниже, предварительно установив пакеты npm:

```
npm i
npm run build
```
