# Что нужно для запуска розыгрыша Si, mamma

Адрес для QR-кода и рекламы после публикации — `https://academia-shuvaloff.ru/simamma?utm_source=simamma`.

| Что требуется | Что осталось сделать |
| --- | --- |
| Полные правила акции | Загрузить утверждённый PDF в S3 под ключом `files/simamma_rules.pdf`. |
| Почта для заявок | Выбран общий ключ Web3Forms «Посейдона». В теме письма указано название ресторана. |
| Google Таблица | Готов [лист «Si, mamma»](https://docs.google.com/spreadsheets/d/1C6YkSo6kYiXZLS3MGANannA_IAfuxwnhfAQBoqerccY/edit#gid=778083107) в общей таблице. |
| Синхронизация | Опубликовать обновлённый обработчик сайта и сохранить [общий скрипт](../poseidon/Code.gs) в существующем проекте Apps Script. |

После подключения проверить одну согласованную тестовую заявку. Её ID должен совпасть в письме менеджеру и строке таблицы. После успешной отправки форма должна открыть `/simamma/thankyou/`. В модуле бронирования проверить, что код `Si, Mamma` применяет скидку 15%.

Лендинг проверяет доступность файла при открытии страницы. После публикации PDF при следующей загрузке страницы станут доступны форма и [правила акции](https://static.academia.spb.ru/files/simamma_rules.pdf).
